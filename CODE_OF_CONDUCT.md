# Code of conduct

This is a small project with one maintainer. The rules are short:

- Be kind and specific. Bug reports with a log and a clear "expected / got" are
  worth more than opinions about the author.
- No harassment, personal attacks, or discrimination of any kind — in issues,
  pull requests, or anywhere else this project is discussed.
- Disagree with decisions on their merits; the maintainer decides what ships.
- If someone's behaviour is a problem, email anton.g.kulikov@gmail.com. Reports
  are read and acted on; you'll get a reply.

Violations get a warning, then a block. That's the whole process.
